About the Algorithm

The Subset Construction Algorithm (also called the Powerset Construction) converts any Non-Deterministic Finite Automaton (NFA) into an equivalent Deterministic Finite Automaton (DFA).

1

ε-Closure

Compute the set of all states reachable from a given state using only epsilon (ε) transitions.

2

Move

For a set of NFA states and an input symbol, find all states reachable via that symbol.

3

Subset Construction

Starting from ε-closure of the start state, iteratively apply Move + ε-Closure for each symbol to discover all DFA states.

4

Mark Finals

Any DFA state (a set of NFA states) that contains at least one NFA final state becomes a DFA final state.
